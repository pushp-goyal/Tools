# Tools

Micro tools for making work simple.

| Tool | What it does |
|---|---|
| [Design Notes for AI](design-notes-extension/) | Browser extension for UI review: click any element on a page, say what should change (with an optional screenshot), keep going across pages, then hand every note to any AI coding agent as one prompt. Chrome, Edge, Brave and other Chromium browsers on macOS, Windows and Linux. |
