Format

Screenshots

Screenshots and saved note files go to Downloads/design-notes/. The copied text lists each file's full path, so agents that can read local files (Claude Code, Codex CLI, Cursor, Gemini CLI, Copilot in VS Code and others) open them on their own. For a chat app in the browser, use Save file in the panel: it saves the notes next to the screenshots and opens the folder so you can drag everything in.

Local files

To use the tool on pages opened as file://, open the extension's details page and turn on Allow access to file URLs.
